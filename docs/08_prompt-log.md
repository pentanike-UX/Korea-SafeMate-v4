# 08 — Prompt / work log

## 복원 불가 안내

과거 Cursor/에이전트 **프롬프트 원문**은 Git에 저장되지 않는다. 이 파일은 **앞으로** 누적하기 위한 로그다.

## 기록 방식

```bash
./scripts/log-work.sh "한 줄 요약"
```

위 스크립트가 이 파일 하단에 타임스탬프와 함께 한 줄을 추가한다.
