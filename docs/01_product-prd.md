# 01 — Product PRD (코드·Git 기반 정리)

> 공식 PRD 원문은 복원 불가. 아래는 **현재 코드와 커밋 메시지**로 역추적한 **제품 설명 초안**이다. 불확실한 항목은 **TODO**로 표시한다.

## 문제 정의 (추정)

- 한국 첫 방문·단기 체류 여행자가 **안전·언어·동선**에서 의사결정 피로를 겪는다.
- 일반 POI 나열이 아니라 **순서가 있는 동선(route)** 과 **로컬 가디언** 신뢰 레이어가 필요하다.

## 핵심 가치 제안 (코드에서 확인되는 범위)

1. **가디언**: 프로필·가이드·예약/매칭 흐름 (`/guardians`, API `match-requests` 등).
2. **여행자 마이페이지**: 저장, 포인트, 매치, 메시지, 리뷰 등 (`/mypage/*`, `/traveler/*`).
3. **v4 큐레이션**: **Route / Spot / Story** 데이터 모델, **AI Planner(목업 입력 → 결과 동선)**, **지도 중심 워크스페이스(Wayly UX)**.

## 주요 페르소나 (추정)

| 페르소나 | 앱 내 흔적 |
|----------|------------|
| Traveler | `traveler/*`, `mypage/*`, 저장·리뷰 API |
| Guardian | `guardian/*`, 가디언 포스트·프로필 API |
| Admin | `/admin/*`, curated 허브 커밋 설명 |

## 기능 범위 (확인됨)

- 다국어 공개 사이트 + 인증 구역 분리 `(public)` / `(authed)`.
- **Map-canvas 그룹**: 홈, 플래너, 플래너 결과, 탐색(라우트·스팟·스토리 등), 스토리 — **아이콘 레일 + 컨텍스트 패널 + 풀스크린 지도**.
- **Site 그룹**: 로그인, 북, 가디언, 포스트, about 등 **기존 사이트형 셸**.
